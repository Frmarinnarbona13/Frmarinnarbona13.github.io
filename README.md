# frmarin.dev

Portfolio de Francisco Marín Narbona: proyectos de 1.º y 2.º de DAW que se pueden probar en el navegador y proyectos personales con IA.

- `index.html`: la web principal (HTML, CSS y JavaScript en un solo archivo).
- `img/`: logo, favicon y foto.
- `proyectos/`: las demos que abre cada botón «Probar».
  - `stemgame/`: frontend original de STEMGAME con la API de Spring Boot simulada (`utils/apiUtils.js`).
  - `api-rest/`, `sql/`, `cines-java/`, `terminal-linux/`, `catalogo-felino/`, `cortacandados/`: simulaciones.
  - `stem-farm/`, `rm-wiki/`, `guemi/`: proyectos originales.
  - `disaster/`: imágenes y modelos 3D de Steal An Disasters.

Para añadir o cambiar proyectos, edita las listas `PROYECTOS` y `PERSONALES` al principio del `<script>` de `index.html`.
